# بيان المستلزمات — الوحدات الصحية بمنية النصر

صفحة لإدخال الرصيد الحالي والاحتياج لمدة ٣ شهور لكل صنف من المستلزمات (٣٩ صنف)، وبتحسب **حد الكفاية** وهو عدد الشهور اللي يكفيها الرصيد، وبيظهر قدام الموظف وهو بيكتب.

- البيانات بتتبعت لجوجل فورم، والشيت المربوط بيه بيحسب حد الكفاية والمطلوب صرفه لكل وحدة.
- الصفحة بتشتغل من غير نت بعد أول فتحة. لو مفيش نت وقت الإرسال، البيان بيتحفظ على الموبايل ويتبعت لوحده أول ما النت يرجع.
- تقدر تتنزل على الشاشة الرئيسية للموبايل كأنها تطبيق.

## الملفات
- `index.html`: الصفحة كلها.
- `sw.js`: ده اللي بيخلي الصفحة تشتغل من غير نت.
- `manifest.webmanifest` والأيقونات: عشان الصفحة تتنزل على الموبايل كتطبيق.
